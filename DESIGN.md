# Korlo — Design System

## Product type

B2B compliance SaaS. Design SERVES the product — product mode, not brand mode.

## Audience

Australian SMB owners. Not technical. Arrived via invoice rejection.
Clean, trustworthy, fast to understand. Not startup-flashy.

## Aesthetic direction

Professional fintech utility. Think Stripe's clarity meets
a government-adjacent tool. Zero decorative elements that
don't carry meaning.

## Typography

Geist Sans — headings and body
Geist Mono — ABNs, invoice numbers, amounts, code snippets

## Colour

Zinc base (shadcn default)
One accent — use for CTAs and success states only
Red for errors and cancelled ABN status
Amber for warnings (not confirmed on Peppol)
Green for confirmed Peppol registration

## Components

shadcn/ui Nova preset
Never: purple gradients, bounce animations, card-in-card layouts,
Inter font, rounded-square icon tiles above headings

## The lookup page specifically

Single focused interaction — ABN input centre stage
Result states must be immediately scannable
CTA must be visually distinct but not aggressive
Mobile first — SMB owners will check this on their phone
